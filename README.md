# Webチェックくん

ホームページの確認・修正コメントをもらうためのページ。考え方は動画の「Vcheckくん」と同じ。
コンセプトは **70歳の方でも使える**：ボタンは大きく、手順は3つ、説明は最小限。

- 始まり：2026-10-28（ポートフォリオで「Webアプリも作れる」と見せたい。お客様には無償で提供）
- 版：0.2.0（A案＝画面写真に書き込む方式）
- 公開：https://takahashi130.github.io/hp-check/ （GitHub：Takahashi130/hp-check）

## 見る人がすること

1. 気になる所を押す（ピンの番号が立つ）
2. 一言書いて（声でも）「追加」
3. 終わったら「レビュー完了」（受け取り口が無いページでは「コメントを全てコピー」してメッセージで送る）

- 上の「パソコン／スマホ」で、見る画面を切り替える。ピンは画面ごとに残る。
- いくつかのページを確認する時は、その下に「1 トップ」「2 会社概要」…の切り替えボタンが出る（コメントの数も出る）。
- 書く欄と全体へのコメントの両方に「画像」「色」「参考URL」がある。
  - 画像：写真の差し替え・参考の画像。受け取り口が無いページでも付けられる（コピーした文に「画像はメッセージに一緒に貼ってください」と出る）。
  - 色：四角を押して色を選ぶ →「この色にしてほしい」。「画面の色を取る（スポイト）」で、写真の上の押した所の色も取れる（ファイルを直接開いた時は取れない）。
  - 参考URL：参考にしたいサイトの URL。
- 書く欄の「描く」で、画面写真の上にペン・矢印・四角・丸・文字（黄・赤・白）を描ける。はじめの色は赤（ホームページは白地が多いので）。
- 「声で入れる」は Chrome・Edge・Safari・スマホのブラウザ（Brave は不可。声はブラウザの音声認識＝Google・Apple・Microsoft に送られる）。
- 場所の決まらないことは「全体へのコメント」へ。
- コメントは見た人のブラウザに残る（閉じても同じブラウザで開けば続きから）。

## 作る人がすること

### 1. 画面写真を撮る（ページごとに1回。直したら撮り直す）

```bash
python 道具/shot.py https://crifa.co.jp/ crifa-top --title "株式会社クリファ トップページ" --label "トップ"
```

- 手元の Edge をヘッドレスで動かし、PC 幅（1440）とスマホ幅（390、iPhone として・2倍の細かさ）の **縦長全体** を撮る。
- できるもの：`pages/<名前>/pc.jpg`・`sp.jpg`・`page.json`・`page.js`（ページはこの page.js を読む。ファイルを直接開いても読めるように）。
- 撮る前に下までゆっくり動かして、あとから出る絵や文字を出しておく。
- 長いページは区切って撮ってつなぐ（一度に撮ると、途中から上の部分がくり返し写るため。2026-10-28 に見つけた）。
- `--label` は切り替えボタンに出す短い名前（トップ・会社概要など）。
- 幅を変える時：`--pc 1280 --sp 375`
- 複数ページは1ページずつ撮る（名前を変えて何回か）。
- 必要なもの：Edge、Python の `websocket-client` と `Pillow`。

### 2. リンクを送る

```
<ページの場所>/index.html?p=<名前>                 … コピーで返してもらう
<ページの場所>/index.html?p=<名前>&to=<受け取り口>   … 「レビュー完了」で直接届く
<ページの場所>/index.html?p=top,about,price          … 複数ページ（カンマでつなぐ。並べた順に切り替えボタンが出る）
```

- `p` が無い時は動作見本（クリファのトップとポートフォリオ）が開く。
- 複数ページの「レビュー完了」は、ページごとに分けて届く（シートの「動画」の列が `hp-<名前>` ごと）。全体へのコメントは最初のページの分と一緒に届く。
- 受け取り口は **Vcheckくんと同じ Google Apps Script**（`E:\YouTube共通ノウハウ\動画確認ページ\道具\receiver\コード.gs`）。作り直しは要らない。
  - シートの「動画」の列に `hp-<名前>`、「時刻」に番号、「時刻の文字」に `PC ①`／`スマホ ①`、「区間」に場所（`上から 377px（4%）・左から 25%`）、「描き込み」に形と位置が入る。
  - 要望・不具合は動画「webcheck-request」で届く。
- 受け取り口の URL は GitHub に置かない（リンクの `to=` で渡す）。

## 届いた文の読み方

```
【株式会社クリファ トップページ】確認コメント 2件（山田）
https://crifa.co.jp/（2026-10-28 10:03 の画面）
【全体】
全体的に文字を大きく
ーーーーー
① パソコン・上から 377px（4%）・左から 25%
　見出しの文字をもう少し大きく
② パソコン・上から 624px（7%）・左から 60%
　ボタンの色を濃く
　✎ 矢印(赤) 216,543→648,428 / 丸(赤) 72,214→792,411 / 文字(黄) 720,181「ここ大きく」
```

- 位置は、画面写真を撮った幅（PC 1440・スマホ 390）でのページの左上からの px（横,縦）。`pages/<名前>/pc.jpg` の同じ所を見れば分かる（スマホの写真は2倍の細かさなので、px を2倍した所）。
- 複数ページの時は「■ トップ　URL」のようにページごとに見出しが付く。番号（①②…）は全ページ通し。
- 「参考：」は参考にしたいサイト、「色：」は「この色に #FF8800」（こうしてほしい色）と「画面の色 #FFFFFF」（スポイトで取った今の色）。
- 「✎」の行は描き込み。`線` は点の列、`矢印`・`四角`・`丸` は始点→終点、`文字` は位置と「文」。

## これから（B案）

自社で作るサイトには、ページに小さな部品を入れて、本物のページの上に直接ピンを立てられるようにする（よそのサイトは iframe 表示を禁止していることが多いので、A案の画面写真方式を先に作った）。
